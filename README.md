# Face Recognition Attendance System

## Description
A Java-based face recognition attendance system using OpenCV and Apache POI.

## Technologies
- Java
- OpenCV
- Apache POI
- Maven

## Features
- Face detection
- Face recognition
- Attendance recording
- Excel-based attendance management

## Project Structure
- DatasetCreator.java – Creates face datasets
- FaceTrainer.java – Trains the face recognition model
- FaceRecognizerApp.java – Performs face recognition
- ExcelWriter.java – Records attendance in Excel

## Note
Personal face images are not included in this repository for privacy reasons.
